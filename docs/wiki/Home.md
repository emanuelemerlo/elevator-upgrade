# Elevator upgrade

**Italiano** — Simulatore di ascensori in C++ con un'interfaccia web per osservarlo, intervenire e confrontare strategie e configurazioni sugli stessi passeggeri. Nato da una gara di una rivista degli anni '80 per Commodore 64, rifatto in C++ moderno e poi esteso con giornata simulata, interfaccia nel browser, confronti, energia, zone dei grattacieli.

**English** — A C++ elevator simulator with a web interface to watch it, intervene and compare strategies and configurations on the same passengers. Born from a 1980s magazine contest for the Commodore 64, rewritten in modern C++ and then extended with a simulated day, a browser interface, comparisons, energy, zoning for tall buildings.
